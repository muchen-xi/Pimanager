# PiManager v2 用户使用指南

> 版本：v2.1.0 | 适用于 Windows / Raspberry Pi OS / 任何 Python 3.9+ 系统

---

## 1. 快速开始

### 1.1 系统要求

| 项目 | 最低要求 |
|------|---------|
| 操作系统 | Windows 10+ / Raspberry Pi OS / macOS / Linux |
| Python | 3.9 及以上 |
| 内存 | 512 MB 以上（推荐 1 GB） |
| 网络 | 能与目标树莓派通过 SSH 通信 |
| 依赖库 | paramiko >= 3.0.0, Pillow >= 10.0.0 |

### 1.2 安装步骤

**第一步：安装 Python 依赖**

在项目根目录（`pimanager/`）下打开终端，执行：

```bash
pip install -r requirements.txt
```

依赖列表（`requirements.txt`）包含两个包：
- **paramiko**（>= 3.0.0）—— SSH/SFTP 协议库，负责与树莓派的远程通信
- **Pillow**（>= 10.0.0）—— 图像处理库，负责 Canvas 渲染层的字体和界面绘制

**第二步：配置 SSH 密钥（推荐）**

PiManager 支持 ed25519 和 RSA 两种密钥格式。推荐使用 ed25519 密钥以提高安全性。

确保密钥文件位于 Windows 默认位置：

```
C:\Users\<你的用户名>\.ssh\id_ed25519
```

如果还没有密钥，在终端中生成：

```bash
ssh-keygen -t ed25519 -C "pimanager"
```

然后将公钥复制到树莓派：

```bash
ssh-copy-id pi@raspberrypi.local
```

**第三步：启动应用**

Windows 用户可以双击项目根目录下的 `启动.bat` 文件。该脚本会自动设置 UTF-8 编码并启动程序。

或通过命令行启动：

```bash
python -m pimanager.main
```

> **提示**：如果提示找不到 `pimanager` 模块，请确认当前工作目录是 `pimanager/` 的**父目录**（即包含 `pimanager/` 文件夹的那个目录），或在启动前执行 `cd` 切换到项目根目录。

### 1.3 首次运行界面说明

启动后，PiManager 主窗口尺寸为 **1100 x 700 像素**（最小 900 x 600），界面分为三个区域：

```
┌──────────────┬──────────────────────────────────────────────┐
│   侧边栏     │               主内容区                       │
│   (240px)   │                                              │
│             │   系统状态 / 文件管理 / 命令终端 / 应用设置   │
│  Logo       │                                              │
│  连接状态    │                                              │
│  连接/断开   │                                              │
│  连接设置    │                                              │
│  导航按钮    │                                              │
│  重启/关机   │                                              │
│  版本号      │                                              │
├──────────────┴──────────────────────────────────────────────┤
│                    底部状态栏                                │
│  连接状态文字  │  已连接时长  │  当前时间                    │
└─────────────────────────────────────────────────────────────┘
```

**侧边栏**（左侧 240px 宽）：
- 🥧 **Logo** 与 "PiManager" 标题（绿色）
- **连接状态卡片**：显示当前连接状态（🔴 未连接 / 🟢 已连接）
- **🔌 连接** 按钮：点击连接或断开树莓派
- **⚙️ 连接设置** 按钮：配置 SSH 连接参数
- **导航按钮**：📊 系统状态 / 📁 文件管理 / 💻 命令终端 / ⚙️ 应用设置
- **电源按钮**：🔄 重启 / ⏻ 关机（连接后可用）
- **版本号**：底部显示当前版本

**主内容区**：根据当前选中的导航标签，显示对应页面。

**底部状态栏**：左侧显示连接状态文字，中间显示已连接时长，右侧显示当前日期时间（每 30 秒自动更新）。

## 2. SSH 连接管理

### 2.1 添加新连接

1. 点击侧边栏的 **⚙️ 连接设置** 按钮，弹出连接设置对话框（450 x 380 像素）
2. 填写以下字段：

| 字段 | 说明 | 默认值 |
|------|------|--------|
| 连接名称 | 自定义标识，仅用于显示 | 树莓派 |
| 主机地址 | 树莓派的 IP 或主机名（支持 `.local` mDNS） | raspberrypi.local |
| 端口 | SSH 端口号 | 22 |
| 用户名 | 登录用户名 | pi |
| 密钥路径 | SSH 私钥文件路径 | C:\Users\\<用户名>\\.ssh\id_ed25519 |

3. 点击密钥路径右侧的 **📂** 按钮可以浏览并选择密钥文件。对话框默认打开 `~/.ssh` 目录，支持以下文件类型：
   - `id_*`（标准密钥文件）
   - `*.pem`（PEM 格式文件）
   - `*.*`（所有文件）

4. 点击 **💾 保存并连接** 可保存配置并自动发起连接；点击 **保存** 仅保存配置。

连接配置保存在项目根目录的 `pimanager.json` 文件中。

### 2.2 连接与断开操作

**手动连接**：点击侧边栏的 **🔌 连接** 按钮。按钮文字会变为 "⏳ 连接中..." 并禁用，连接成功后自动恢复。

- 连接超时：10 秒
- 认证方式：优先密钥认证，其次是密码认证
- 支持的密钥格式：ed25519、RSA

**断开连接**：连接状态下按钮文字显示 "🔌 断开"（红色危险样式），点击即可断开。

**自动重连**：连接意外断开时，PiManager 会自动尝试重连，采用指数退避策略（1 秒、2 秒、4 秒），最多重试 3 次。

**连接保活**：连接建立后，后台每 30 秒发送一次轻量保活命令（`echo "keepalive"`），防止长时间无操作导致连接超时断开。

**自动连接**：在设置中开启 "启动时自动连接树莓派" 后，每次启动 PiManager 都会自动使用第一个连接配置发起 SSH 连接。

### 2.3 连接状态指示器

连接状态实时反映在侧边栏中：

| 图标 | 状态 | 说明 |
|------|------|------|
| 🔴 未连接 | 未连接 | 尚未连接到任何树莓派 |
| ⏳ 连接中... | 连接中 | 正在尝试建立 SSH 连接 |
| 🟢 已连接 | 已连接 | SSH 连接正常，可执行操作 |
| 🔴 连接失败 | 失败 | 连接失败，显示具体错误原因 |

连接成功后，侧边栏会自动展开 **实时状态** 卡片，显示 CPU 使用率、内存使用率、IP 地址和温度等精简信息。

### 2.4 保存和管理多个连接

当前版本支持保存一个连接配置。配置存储在 `pimanager.json` 中，结构如下：

```json
{
  "connections": [
    {
      "name": "树莓派 Zero W",
      "host": "raspberrypi.local",
      "port": 22,
      "username": "pi",
      "key_path": "C:\\Users\\...\\.ssh\\id_ed25519",
      "use_key": true
    }
  ]
}
```

### 2.5 密钥认证配置

PiManager 自动检测密钥文件格式：

1. 首先尝试以 **ed25519** 格式加载密钥
2. 如果失败，尝试以 **RSA** 格式加载
3. 如果密钥路径存在但格式不识别，返回 "密钥格式不支持或无效" 错误
4. 如果未提供密钥路径但提供了密码，则使用密码认证
5. 如果既未提供密钥也未提供密码，返回 "请提供密钥或密码" 错误

> **Windows 用户注意**：密钥路径使用 Windows 格式（如 `C:\Users\用户名\.ssh\id_ed25519`）。确保私钥文件权限正确，没有被其他程序占用。

### 2.6 树莓派电源控制

连接成功后，侧边栏底部的两个电源按钮变为可用：

- **🔄 重启**：点击后弹出确认对话框，确认后向树莓派发送 `sudo shutdown -r now` 命令。重启期间连接将断开，约 30 秒后可重新连接。
- **⏻ 关机**：点击后弹出确认对话框，确认后向树莓派发送 `sudo shutdown -h now` 命令。**关机后需手动重新上电才能启动**。

## 3. 状态监控

点击侧边栏 **📊 系统状态** 进入状态监控页面。所有监控数据通过**一次 SSH 远程调用**合并获取（优化响应速度），在后台线程中执行，不会阻塞界面。

### 3.1 CPU 使用率

**🔥 CPU** 卡片显示当前 CPU 总体使用率百分比。

- 大号数字（22px 粗体）显示百分比值
- 进度条以颜色编码：
  - **绿色**（< 50%）：正常负载
  - **橙色/黄色**（50% - 80%）：中等负载
  - **红色**（>= 80%）：高负载

### 3.2 内存使用

**🧠 内存** 卡片显示系统内存使用情况。

- 显示格式：`已用 / 总计 MB`（如 `180 / 427 MB`）
- 进度条颜色编码与 CPU 相同

### 3.3 磁盘空间

**💾 磁盘** 卡片显示根分区磁盘使用情况。

- 总容量 >= 1 GB 时以 GB 为单位显示（如 `4.5 / 29.0 GB`）
- 总容量 < 1 GB 时以 MB 为单位显示
- 进度条颜色编码与 CPU 相同

### 3.4 系统温度

**🌡️ 温度** 卡片显示 CPU 温度。

- 大号数字（26px 粗体）显示温度值
- 颜色编码：
  - **绿色**（< 50°C）：正常温度
  - **橙色/黄色**（50°C - 70°C）：偏高
  - **红色**（>= 70°C）：警告，需关注散热

> 温度数据来源于树莓派的 `/sys/class/thermal/thermal_zone0/temp`，单位为千分之一摄氏度，PiManager 自动转换为摄氏度显示。

### 3.5 运行时间与负载

**底部信息卡片** 显示：

- ⏱ **运行时间**：系统自上次启动以来的运行时长（如 `up 3 days, 2 hours, 15 minutes`）
- 📊 **负载**：系统 1 分钟、5 分钟、15 分钟的平均负载

### 3.6 系统信息

**🖥️ 系统信息** 卡片顶部显示：

- 主机名（连接前显示 "🔴 未连接"）
- 操作系统版本（如 `Raspberry Pi OS (bookworm)`）
- Linux 内核版本（如 `6.12.75+rpt-rpi-v6`）

### 3.7 自动刷新机制

- 连接成功后**自动开始**刷新（默认每 3 秒一次）
- 点击 **🔄 刷新** 按钮可手动立即刷新一次
- 最后更新时间显示在刷新按钮左侧，格式为 `HH:MM:SS`
- 刷新间隔可在 **应用设置 → 行为设置** 中调整（范围：1-30 秒）
- 断开连接后自动停止刷新
- 侧边栏的实时状态卡片也独立保持 3 秒刷新（用于导航至其他页面时仍能监控核心指标）

## 4. 文件管理器

点击侧边栏 **📁 文件管理** 进入文件管理页面。文件管理器基于 Canvas 原生绘制，支持双栏布局。

### 4.1 布局说明

文件管理器默认以**单栏模式**显示远程文件列表。点击工具栏的 **双栏** 按钮可切换为双栏模式：

```
单栏模式：
┌──────────────────────────────────────────────────────┐
│ [双栏] [上传] [下载] [运行] [新建] [重命名] [删除]     │
├──────────────────────────────────────────────────────┤
│                                                      │
│           远程树莓派文件列表                           │
│                                                      │
├──────────────────────────────────────────────────────┤
│ 状态信息                                  [进度条]    │
└──────────────────────────────────────────────────────┘

双栏模式：
┌──────────────────────┬───────────────────────────────┐
│ [单栏] [下载到本地]   │ [上传到树莓派]                 │
│ [上传] [下载] [运行]  │ [新建] [重命名] [删除]          │
├──────────────────────┼───────────────────────────────┤
│    远程文件列表       │      本地文件列表              │
│    （蓝色文件名）     │      （蓝色文件名）            │
│                      │                               │
├──────────────────────┴───────────────────────────────┤
│ 状态信息                                  [进度条]    │
└──────────────────────────────────────────────────────┘
```

- **远程文件列表**：显示树莓派上的文件和目录，蓝色系文件名
- **本地文件列表**：显示本地计算机的文件和目录，蓝色系文件名（默认打开用户主目录 `~`）

### 4.2 浏览远程目录

- **双击目录**：进入该目录，自动刷新文件列表
- **鼠标滚轮**：上下滚动文件列表
- **单击**：选中文件或目录（高亮显示，浅色主题为浅绿背景，深色主题为深绿背景）
- **右键菜单**：弹出上下文菜单，包含下载、运行（仅文件）、重命名、删除、新建文件夹等选项

文件列表每行显示：
- 目录标记 `DIR` 或普通文件
- 文件名（过长时自动截断加 `..`）
- 文件大小（自动转换单位：`K` 千字节、`M` 兆字节）
- 修改时间（格式：`MM-DD HH:MM`）

目录排序规则：目录优先，再按名称字母序排列。

### 4.3 上传文件到远程

**方式一（单栏模式）**：

1. 浏览到远程目标目录
2. 点击工具栏 **上传** 按钮
3. 在弹出的文件选择对话框中选择一个或多个文件
4. 文件将上传到当前远程目录

**方式二（双栏模式）**：

1. 切换到双栏模式
2. 在本地列表中选中要上传的文件
3. 点击右键菜单中的 **上传到树莓派**，或直接点击工具栏的 **上传到树莓派** 按钮
4. 文件将上传到当前远程目录

### 4.4 下载文件到本地

**方式一（单栏模式）**：

1. 选中远程文件
2. 点击工具栏 **下载** 按钮
3. 选择本地保存目录
4. 文件下载到指定位置

**方式二（双栏模式）**：

1. 切换到双栏模式
2. 在本地列表中浏览到目标目录
3. 在远程列表中选中文件
4. 点击 **下载到本地** 按钮或右键菜单中的 **下载**
5. 文件直接下载到当前本地目录，无需弹出选择对话框

### 4.5 删除与重命名远程文件

**删除**：

1. 选中要删除的远程文件或目录
2. 点击工具栏 **删除** 按钮
3. 确认删除对话框（可在设置中关闭确认提示）
4. 支持递归删除目录（迭代方式，避免大目录栈溢出）

**重命名**：

1. 选中要重命名的远程文件
2. 点击工具栏 **重命名** 按钮
3. 文件将在原名前添加 `renamed_` 前缀

**新建文件夹**：

1. 浏览到目标远程目录
2. 点击工具栏 **新建** 按钮
3. 在当前远程目录下创建名为 `新建文件夹` 的目录

### 4.6 远程脚本一键执行

PiManager 可一键执行树莓派上的远程脚本，无需手动打开终端输入命令。

1. 在远程文件列表中选中脚本文件
2. 点击工具栏 **运行** 按钮（绿色高亮）

PiManager 根据文件扩展名自动选择解释器：

| 扩展名 | 解释器 | 执行命令 |
|--------|--------|---------|
| `.py` / `.py3` | Python 3 | `python3 <文件>` |
| `.sh` / `.bash` | Bash | `bash <文件>` |
| 其他 | 先加执行权限再运行 | `chmod +x <文件> && <文件>` |

执行逻辑：如果终端页面已打开，会将命令自动推送到终端页的一个新标签中执行；否则弹出独立的运行结果窗口显示 stdout、stderr 和退出码。

> **安全提示**：运行远程脚本前请确认脚本内容可信。脚本在树莓派上以当前 SSH 用户权限执行。

### 4.7 传输进度显示

上传和下载操作均支持实时进度显示：

- 底部状态栏出现 **进度条**，百分比实时更新
- 状态栏文字显示 `上传中...` 或 `下载中...`
- 传输完成后进行**文件大小校验**：对比远程和本地字节数，不匹配时提示错误
- 传输完成 3 秒后状态栏文字自动清空
- 传输成功后自动刷新文件列表

## 5. 终端

点击侧边栏 **💻 命令终端** 进入终端页面。终端基于 Canvas 原生渲染，支持多标签、流式输出和历史记录。

### 5.1 多标签终端

终端页面支持**同时打开多个独立会话标签**：

- 启动时自动创建一个名为 "终端 1" 的标签
- 点击标签栏右侧的 **＋ 新建** 按钮或底部工具栏的 **＋ 新终端** 按钮创建新标签
- 点击标签按钮可在会话之间切换
- 当前激活的标签以绿色高亮显示
- 每个标签拥有独立的命令历史（最多 500 条）

### 5.2 命令执行

终端支持两种执行模式，通过输入框右侧的 **流式:关/流式:开** 按钮切换：

**阻塞模式（流式:关，默认）**：

- 命令执行完毕后才一次性返回全部输出
- 适用于运行时间短的命令
- 超时时间：30 秒

**流式模式（流式:开）**：

- 命令输出逐行实时推送到终端
- 适用于长时间运行的命令（如持续日志输出、服务监听等）
- 使用 PTY（伪终端）分配，确保远程进程的行缓冲模式
- 超时时间：120 秒
- 此模式下 "发送" 按钮变为 "停止" 按钮

**执行步骤**：

1. 在底部输入框输入命令
2. 按 **Enter** 或点击 **发送** 按钮
3. 命令提示符 `$ <命令>` 显示在终端输出区
4. 标准输出以白色/浅色显示，标准错误以**红色**显示
5. 命令结束后显示退出码（非 0 时以红色 `[exit: N]` 显示）

### 5.3 流式输出显示

终端输出区基于 Canvas 原生绘制，特性如下：

- 文字使用微软雅黑（Microsoft YaHei）10px 字体渲染
- 支持**虚拟滚动**：输出内容超出可视区域时自动显示滚动条
- **自动滚屏**：新输出到达时自动滚动到底部
- 手动滚动后自动滚屏暂停，不再跟随新输出（适合查看历史输出）
- 单行最長显示 120 个字符，超出截断
- 深色主题下 stdout 为浅灰色 `#C9D1D9`，stderr 为红色 `#FF6B6B`，提示符为绿色 `#4CAF50`

### 5.4 快捷键

**输入框快捷键**：

| 快捷键 | 功能 |
|--------|------|
| `Enter` | 发送当前输入的命令 |
| `↑`（上箭头） | 浏览上一条历史命令 |

**Ctrl + C 终止机制**（流式模式）：

1. 首次按 `Ctrl + C`：向远程进程发送 SIGINT 信号（Ctrl+C 字符 `\x03`），优雅终止
2. 等待 1.5 秒
3. 如果进程仍未退出：强制关闭 SSH 通道，并在终端显示 "进程未响应，已强制关闭"

### 6.3 自定义背景图片

**🖼️ 背景设置** 卡片：

1. 点击 **📂 选择图片** 按钮，浏览并选择背景图片
   - 支持格式：JPG、JPEG、PNG、BMP、GIF
2. 选中后图片立即生效。当前背景文件名显示在按钮上方
3. 点击 **🗑 清除背景** 按钮移除背景，恢复纯色背景

**背景渲染机制**：

PiManager 的背景并非简单叠加，而是采用**图层混合**技术：
1. 将选择的背景图片加载为 RGBA 模式
2. 创建一个与图片等大的纯色底层（深色模式为 `#0D1117`，浅色模式为 `#FFFFFF`）
3. 通过 PIL `Image.blend()` 按设定的透明度混合两个图层
4. 混合结果统一应用到所有页面的 Canvas 上

这种设计的优势：
- 不会因背景图片过亮或过暗影响文字可读性
- 透明度可精确控制背景可见程度
- 所有页面共享同一张混合背景，切换页面时背景一致

### 6.4 背景透明度调节

## 7. 树莓派 Zero W 部署

### 7.1 远程连接树莓派的推荐配置

**树莓派端准备**：

1. 确保 SSH 服务已启用：
   ```bash
   sudo systemctl enable ssh
   sudo systemctl start ssh
   ```

2. 配置 mDNS（Avahi）以便使用 `.local` 主机名访问：
   ```bash
   sudo apt update
   sudo apt install avahi-daemon
   ```

3. 创建用户并添加 SSH 公钥：
   ```bash
   mkdir -p ~/.ssh
   chmod 700 ~/.ssh
   # 将公钥内容追加到 authorized_keys
   echo "你的ed25519公钥内容" >> ~/.ssh/authorized_keys
   chmod 600 ~/.ssh/authorized_keys
   ```

**PiManager 端配置（Windows）**：

1. 确保 SSH 密钥文件路径正确，推荐使用 ed25519 密钥
2. 主机地址可使用：
   - mDNS 主机名：`raspberrypi.local`（需要在同一局域网）
   - IP 地址：`192.168.x.x`（更可靠，但 IP 可能变动）
3. 端口保持默认 `22`

### 7.2 SSH 性能优化建议

**针对树莓派 Zero W 的优化**：

PiManager 已内置以下优化措施，无需用户手动配置：

- **合并 SSH 调用**：系统状态获取将 CPU、内存、磁盘、温度等数据合并为**一次 SSH 往返**，避免多次连接开销
- **异步执行**：所有 SSH 操作均在后台线程中执行，不阻塞 UI 响应
- **保活机制**：每 30 秒发送保活信号，避免连接空闲超时

**树莓派端可选优化**：

在树莓派上编辑 `/etc/ssh/sshd_config`，添加或修改以下配置：

```
# 缩短保活间隔
ClientAliveInterval 30
ClientAliveCountMax 3

# 禁用 DNS 反向解析（加速连接建立）
UseDNS no
```

修改后重启 SSH 服务：

```bash
sudo systemctl restart ssh
```

**连接参数建议**：

| 场景 | 刷新间隔 | 推荐连接方式 |
|------|----------|-------------|
| 局域网有线 | 1-3 秒 | mDNS 主机名 或 IP |
| 局域网 Wi-Fi | 3-5 秒 | IP 地址（更稳定） |
| 跨网段 / VPN | 5-10 秒 | IP 地址 + 增加超时时间 |

### 7.3 低带宽模式注意事项

当通过移动热点、4G 网络或慢速 Wi-Fi 连接树莓派时：

1. **增大刷新间隔**：在设置中将状态刷新间隔调至 5-10 秒
2. **避免大文件传输**：大文件传输在低带宽下耗时较长，请耐心等待进度条完成
3. **优先使用流式终端**：长时间命令建议使用流式模式，可实时查看输出进度
4. **减少同时操作**：避免在上传/下载文件的同时频繁刷新状态或执行命令
5. **关闭自动刷新**：在文件管理或终端页面长时间工作时，可切换回状态页面手动停止自动刷新以节省带宽

## 8. 常见问题

### 8.1 连接超时怎么办？

**现象**：点击连接后长时间无响应，最终提示 "连接失败" 或 "认证失败"。

**排查步骤**：

1. **检查网络连通性**：在终端中 ping 树莓派地址
   ```bash
   ping raspberrypi.local
   ```
   如果 ping 不通，检查两台设备是否在同一局域网。

2. **检查 SSH 端口**：确认树莓派 SSH 运行在端口 22，且未被防火墙拦截。

3. **检查密钥路径**：确认 `pimanager.json` 中的 `key_path` 指向有效的私钥文件。文件路径必须是完整的绝对路径。

4. **检查密钥权限**：Windows 下确保私钥文件未被其他程序占用。

5. **尝试密码认证**：在连接设置中清空密钥路径，填写密码进行测试，确认 SSH 服务本身可用。

6. **检查树莓派 SSH 日志**：在树莓派上执行
   ```bash
   sudo journalctl -u ssh -f
   ```
   查看实时日志，定位认证失败原因。

### 8.2 中文显示乱码？

**现象**：终端输出或文件列表中的中文显示为乱码或方块。

**解决方案**：

1. PiManager 所有文件 IO 均使用 `utf-8` 编码。终端输出在接收时已做 `decode('utf-8', errors='replace')` 处理，无法解码的字符会被替换。

2. 确保树莓派的系统语言环境支持 UTF-8：
   ```bash
   sudo locale-gen zh_CN.UTF-8
   export LANG=zh_CN.UTF-8
   ```

3. Windows 下 `启动.bat` 已设置 `chcp 65001`（UTF-8 代码页）。如果手动命令行启动，确保终端支持 UTF-8。

4. 界面字体使用 **微软雅黑（Microsoft YaHei）**，支持中文显示。如果系统中缺少该字体，可能导致中文显示异常。请确保系统中安装了微软雅黑字体。

### 8.3 文件传输失败？

**现象**：上传或下载文件时提示失败，或文件大小不匹配。

**可能原因与解决**：

1. **权限不足**：确保 SSH 用户对目标目录有读写权限。
   ```bash
   # 检查目录权限
   ls -la /目标/目录
   ```

2. **磁盘空间不足**：树莓派磁盘已满时上传会失败。先检查磁盘空间（终端执行 `df -h`）。

3. **文件名包含特殊字符**：避免文件名中使用 `:`, `*`, `?`, `<`, `>` 等特殊字符。

4. **路径不存在**：确保远程目录路径存在。可在文件管理器中先浏览到目标目录。

5. **大小校验失败**：PiManager 在传输完成后会对比远程和本地文件大小。如果大小不匹配，通常是由于传输中断（网络波动）或磁盘空间不足导致的截断，请重试。

### 8.4 终端无响应？

**现象**：发送命令后终端无输出，或界面卡顿。

**解决方案**：

1. **检查连接状态**：确认侧边栏显示 🟢 已连接。如果连接已断开，终端命令无法执行。

2. **长时间命令使用流式模式**：对于监听类或持续输出的命令（如 `tail -f`），切换到流式模式（点击 **流式:开**）。

3. **强制终止卡住的命令**：流式模式下按 `Ctrl + C` 终止当前命令。如果第一次 Ctrl+C 无效，等待 1.5 秒后系统会自动强制关闭通道。

4. **新建终端标签**：如果某个标签卡死，点击 **＋ 新建** 创建新标签继续工作。

5. **重启连接**：如果所有终端都无法响应，尝试点击 **断开** 后重新 **连接**。

### 8.5 背景图片不显示？

**现象**：在设置中选择了背景图片，但界面背景仍然是纯色。

**排查步骤**：

1. **检查文件格式**：支持的格式为 JPG、JPEG、PNG、BMP、GIF。其他格式可能导致加载失败（查看控制台错误日志）。

2. **检查透明度**：背景透明度默认 15%，如果调至过低（如 5%），背景图片可能几乎不可见。尝试调高透明度至 25-30% 看效果。

3. **确认文件路径有效**：如果图片文件被移动或删除，背景会自动恢复为纯色。

4. **控制台查看错误**：背景加载失败时会在控制台输出 `背景加载失败: 错误信息`，可从命令行启动 PiManager 查看具体错误。

5. **主题切换后**：切换深色/浅色主题会触发背景重新混合渲染，等待约 200ms 即可看到效果。

### 8.6 文字周围有暗色小框/阴影（v2.1.0 已修复）

**现象**：按钮、标签等文字周围出现暗色小方框，尤其在亮色主题下非常明显。

**原因**：Pillow `draw.text()` 在透明 RGBA 图层上绘制文字时，抗锯齿边缘像素与透明背景混合产生暗晕。v2.0.0 及更早版本受此问题影响。

**解决**：升级到 v2.1.0 即可。新版本采用两阶段文字渲染：先在 RGB 不透明层绘制文字 → 分离 alpha 通道 → 合成到透明图层，彻底消除暗晕。

### 8.7 背景图片拉伸变形（v2.1.0 已修复）

**现象**：背景图片被拉伸变形，或图片显示不全有黑边。

**原因**：v2.0.0 仅支持 `fill` 模式（拉伸填充），不同比例的图片会变形。

**解决**（v2.1.0）：在 **应用设置 → 背景设置 → 适配模式** 下拉菜单中选择合适的模式：
- **cover**（默认）：等比缩放填满窗口，裁剪超出部分，不变形
- **contain**：等比缩放完整显示，可能留白，不变形
- **fill**：拉伸填充（旧版行为），可能变形
- **tile**：原始尺寸平铺，适合纹理图片

### 8.8 配置文件损坏怎么办？

**现象**：启动时提示 `配置文件损坏`。

PiManager 内置**自动备份恢复机制**：

1. 每次保存配置前自动备份到 `pimanager/config_backups/` 目录
2. 最多保留最近 10 个备份文件，格式为 `pimanager_YYYYMMDD_HHMMSS.json`
3. 配置文件损坏时自动尝试从最近备份恢复
4. 如果所有备份都无法恢复，使用默认配置启动

手动恢复备份：在 `config_backups/` 目录中找到需要的备份文件，手动复制到上级目录并重命名为 `pimanager.json`。

### 8.9 窗口关闭后连接未断开？

PiManager 在窗口关闭时（点击 X 按钮）会自动执行清理流程：

1. 停止侧边栏自动刷新定时器
2. 停止状态栏时钟定时器
3. 停止状态页面自动刷新
4. 断开 SSH 连接（关闭 Shell 通道、SFTP、SSH 客户端）
5. 销毁窗口

正常情况下连接会完全断开。如果遇到异常情况（如程序崩溃），SSH 连接可能残留。可以在树莓派上查看并清理：

```bash
# 查看当前 SSH 连接
ss -tnp | grep :22
# 或
who
```

## 附录 A：配置文件参考

配置文件 `pimanager.json` 位于项目根目录，完整结构如下：

```json
{
  "version": 2,
  "connections": [
    {
      "name": "树莓派 Zero W",
      "host": "raspberrypi.local",
      "port": 22,
      "username": "pi",
      "key_path": "C:\\Users\\用户名\\.ssh\\id_ed25519",
      "use_key": true
    }
  ],
  "appearance": {
    "theme": "dark",
    "color_theme": "green",
    "background_path": "",
    "background_opacity": 0.15,
    "font_scale": 1.0
  },
  "behavior": {
    "auto_connect": false,
    "refresh_interval": 3,
    "confirm_before_delete": true,
    "terminal_history_size": 500
  }
}
```

配置项说明：

| 路径 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `version` | int | 2 | 配置文件版本号（自动管理） |
| `connections[0].name` | str | "树莓派 Zero W" | 连接名称 |
| `connections[0].host` | str | — | 主机地址 |
| `connections[0].port` | int | 22 | SSH 端口 (1-65535) |
| `connections[0].username` | str | — | 登录用户名 |
| `connections[0].key_path` | str | — | 私钥文件路径 |
| `connections[0].use_key` | bool | true | 是否使用密钥认证 |
| `appearance.theme` | str | "dark" | 主题模式: "dark" / "light" |
| `appearance.color_theme` | str | "green" | 颜色主题: "green" / "blue" / "dark-blue" |
| `appearance.background_path` | str | "" | 背景图片路径（空=不使用） |
| `appearance.background_opacity` | float | 0.15 | 背景透明度 (0-1) |
| `appearance.font_scale` | float | 1.0 | 字体缩放倍数 (0.5-3.0) |
| `behavior.auto_connect` | bool | false | 启动时自动连接 |
| `behavior.refresh_interval` | int | 3 | 状态刷新间隔秒数 (1-60) |
| `behavior.confirm_before_delete` | bool | true | 删除前确认 |
| `behavior.terminal_history_size` | int | 500 | 终端历史记录容量 |
